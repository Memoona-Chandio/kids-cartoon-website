# 📺 Kids Cartoon Website

Kids Cartoon is a simple HTML website that provides information about popular children's cartoon shows.

The website displays cartoon images, short descriptions, and links where users can watch cartoon videos.

## ✨ Features

- Cartoon information
- Cartoon images
- Short descriptions
- Video links
- Multiple cartoon sections
- Simple webpage layout

## 📺 Cartoons Included

The website includes different popular kids cartoons such as:

- Dragon Tales
- Doraemon
- Oggy and the Cockroaches
- Johnny Test

## 🛠️ Technologies Used

- HTML
- Inline CSS styling

## 📁 Main File

- `Kids_Cartoon.html` - Main cartoon webpage

The project also uses image files for different cartoon characters and shows.

## 🚀 How to Run

1. Download or clone the repository.
2. Keep the HTML file and images together.
3. Open `Kids_Cartoon.html` in your browser.
4. Browse the cartoon information and video links.

## 🎯 Project Purpose

The purpose of this project is to practice basic HTML concepts such as headings, images, text formatting, links, and webpage structure.
